# 2 µm 三粒子真实物镜 POP 对照状态

本目录保留 2026-09-03 的原生 OpticStudio POP 诊断，但当前像面结果**不得作为有效的 Python/Zemax 性能对照**。

## 已验证有效的部分

- 使用现有 Python 2 µm 三粒子函数生成输入，未修改 Python 模型。
- 二维复振幅保持原 Python 案例方向，不做转置：横条纹周期沿物方 Y，频谱级次沿傅里叶 Y 排列。
- 档杆不随案例图旋转，严格采用最终工程关系：长轴沿傅里叶 Y、沿傅里叶 X 独立定位。因此该原图工况主要由中央杆覆盖 Y 向级次，用于同图输入一致性检查，不作为七个 X 向杆位都被利用的证明。
- ZBF 起始面与 Python 输入的逐像素强度相关系数为 `0.99999999999995`。
- 波长 355 nm、物方 NA 0.60、30 mm 标称焦距、20×、36 mm 光瞳和 7 杆尺寸均已写入独立 Zemax 模型。

## 原生 POP 为什么失效

2 µm 周期要求大口径中间面采样间隔不大于约 1 µm。当前真实物镜的中间计算窗口达到 36–40 mm；1024² 网格在 40 mm 面上的间隔约 39 µm。原生逐面 POP 在到达真实后焦面之前已经丢失 2 µm 载频。

512² 后焦面诊断中，理论应位于 ±5.166、±10.331、±15.497 mm 的频谱级次只剩零级的约 `10^-9` 至 `10^-11`。因此最后的平滑像面和由它计算的滤波指标不具备物理意义。

即使提高到 2048² 仍远低于两点/周期所需的约 40000 点方形网格，不能作为有效修复。

## 后续可选的有效方法

1. 对非相干二维物体使用 Zemax Huygens PSF / Partially Coherent Image Analysis，再按同一物体强度图成像；这是物理上更适合扩展非相干物体的方法。
2. 使用真实 Zemax 光线给出的 BFP 映射和二维 OPD 构造高 NA 传递函数，再进行频域传播；这是现有工程中已经验证的模型来源联合方法，但不应称为全程原生 POP。

在选择下一种方法前，不引用本目录中的平滑 POP 像面作为滤波性能结论。
