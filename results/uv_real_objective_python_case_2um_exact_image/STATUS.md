# 2 µm 原图不转置：真实物镜 POP 状态

本目录是按用户指定方向重跑的工况：Python 案例图片不转置，三颗粒子仍位于物方
`X = -12, 0, +12 µm`、`Y = 0`；仅仿真 `2 µm` 周期。

## 坐标与档杆

- 原图为横向条纹，周期沿物方 Y，频谱级次沿傅里叶 Y 排列。
- 档杆不随案例图旋转，严格采用最终工程文档：长轴沿傅里叶 Y，沿傅里叶 X 独立定位。
- 因此这个原图工况主要由 `X_F = 0` 的中央杆覆盖 Y 向级次；它用于原图输入一致性核对，不能证明七个 X 向杆位都被周期级次利用。

## 已验证

- 执行环境：`E:\anconda\envs\lens-design-zemax22`。
- OpticStudio：2022 R2.02，原生 POP。
- Python 模型未修改，输入图未转置。
- Zemax S1 与 Python 输入强度的逐像素相关系数：`0.9999999999999557`。
- Open 像面输出功率：`1 W`；Filtered 数值输出功率：`0.0038294314 W`。

## 重要限制

上述 Filtered 数值不能解释为真实滤波性能。1024² 时，S1 的 0.12 mm 物面采样
间隔为 0.117 µm；传播到第一片真实折射面 S2，窗口立即扩为 8.61 mm，间隔变成
8.41 µm，而承载 2 µm 横向空间频率要求间隔不大于约 1 µm。首次折射后重采样
就在这里违反 Nyquist。后续窗口继续增至 23–40 mm，间隔达到约 23–39 µm；
40 mm 窗按两点/周期至少需要约 40000 点/轴。

到后焦面时，理论 `m = ±1, ±2, ±3` 位置的强度只剩零级的约
`8.4e-10、6.9e-11、2.2e-11`，级次在到达档杆之前已数值丢失。关闭
`ResampleAfterRefraction` 也不是修复：它产生约 ±7.59 mm 的强假峰，而理论一级
应为 ±5.166 mm，说明高频被混叠到错误位置。开启该选项时欠采样高频被插值抹掉；
关闭时则保留错误的混叠频率。

所以当前有效结论只有：输入与方向已严格一致；原生逐面 POP 的像面结果受采样
限制失效。不能引用几乎全黑的 Filtered 图作为消光结论。
